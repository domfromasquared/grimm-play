# Grimm

A reaper's night in the Quick and the Still — a 2.5D graveyard puzzle-platformer.

**Play it in your browser: https://domfromasquared.github.io/grimm-play/**

Desktop browser with a keyboard (Chrome, Edge, Firefox or Safari with WebGL 2). The first load is about 60 MB.

| Keys | Action |
|---|---|
| `A` `D` or arrows | Run |
| `Space` / `W` | Jump — let go early for a short hop; by a reaper's hook, Jump again to swing off |
| `Shift` / `F` | Flicker — swap the world, Quick ⇄ Still |
| `S` / `↓` on the ground | Slash |
| `S` / `↓` in the air | Drop Reap |
| `L` | The night's manifest |
| `Esc` / `P` | Pause |

Your nights are remembered in this browser's storage.

This repository holds only the built game (Godot 4.7.2 web export). The fonts it bundles are free fonts; their licences are in `licenses/`.
